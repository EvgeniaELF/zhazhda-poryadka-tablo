# Табло «Жажда порядка»

Рабочая схема: **Telegram → Selectel → Buildin → GitHub → Telegram**.

- **Telegram** — пульт владельца: выбор участника, круга, старта или финиша.
- **Selectel** — постоянно работающий бот. Проверяет владельца и событие, сохраняет его в Buildin, запрашивает обновление GitHub. Компьютер владельца можно выключить.
- **Buildin** — таблицы участников и событий, связи между ними.
- **GitHub Actions и Pages** — чтение Buildin, сборка и публикация табло, затем отправка личной ссылки владельцу и меню ниже неё.

Облачная функция, локальный адаптер, входящий HTTP-сервер и домен для бота не требуются.

## Карта файлов

| Файл / папка | Назначение |
|---|---|
| `index.html` | Рабочая страница и исходная историческая часть данных |
| `personal-links.js` | Личные карточки, ссылки и действия на сайте |
| Изображения и SVG в корне | Оформление страницы и карточек |
| `buildin-sync.json` | ID двух таблиц; это идентификаторы, доступ к API требует токена |
| `scripts/buildin-board.cjs` | Чтение Buildin, проверка и сборка `_site/` |
| `scripts/notify-publication.cjs` | Проверка опубликованного выпуска и отправка карточек / меню |
| `.github/workflows/buildin-board.yml` | Проверки, сборка, публикация и уведомление |
| `tests/` | Автоматические проверки сборки, карточек и отправки |
| `BUILDIN-SYNC.md` | Настройки и правила синхронизации |
| `PERSONAL-LINKS.md` | Сообщения с карточками и разбор доставки |

Серверный пульт уже установлен на Selectel; подтверждённая рабочая версия — 1.2.2. Его установка и резервные копии описаны в отдельной памятке Selectel. Ключи, серверный `bot.json`, курсор очереди и резервные копии сервера в этот репозиторий не загружаются.

## Проверки

```sh
node --test tests/*.test.cjs
```

Workflow использует Node.js 24. Страница публикуется только из основной ветки. Сборщик копирует в `_site/` рабочую страницу, 14 ресурсов оформления, `personal-links.js`, `participation.js` и `cards.json`. Документация, тесты и настройки доступа в сайт не включаются.

Карточки публичные. Личная ссылка выбирает участника и круг; она не является паролем. Открытую вкладку табло обновляют вручную.

Управление составом и пит-стопами: [PARTICIPANTS.md](PARTICIPANTS.md). Включается отдельно после предпросмотра; по умолчанию сохраняется прежний способ чтения участников.
