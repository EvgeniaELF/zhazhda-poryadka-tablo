# Личные карточки и меню · отправитель 1.2.2

После успешной публикации GitHub отправляет владельцу карточки и затем отдельное меню. Этот порядок проверен в рабочем боте 30 октября 2026 года после перехода на Beget.

## Вид сообщения

> ✅ Карточки обновлены.
>
> Старт 17 круга · принят 🏎️
> карточки Личный трек и Личный рубеж можно посмотреть и скачать тут: Болид №7

Название участника — ссылка на его карточки с выбранным кругом. Для финиша выводится «Финиш N круга · принят 🏎️». Имя и адрес экранируются для Telegram HTML. Длинный технический URL, предпросмотр и кнопка под карточками не выводятся.

Следом приходит «Выбери следующее действие.» с кнопками «Ещё отметка в этом круге» (`r:N`) и «← В меню» (`home`). Пульт редактирует меню; сообщение с карточками остаётся выше и подходит для пересылки участнику.

При успешном запросе карточек Beget заменяет сообщение подтверждения отметки на квитанцию без кнопок. Он не добавляет второе сообщение «Сохранить отметку?». До публикации карточек квитанция сообщает об ожидании; меню можно открыть командой `/start`.

## Доставка

Отправитель проверяет репозиторий, workflow, ветку, событие запуска, run/attempt/SHA, опубликованный HTML и `cards.json`. Событие должно однозначно указывать на участника. Перед отправкой проверяется собственный бот; адресат берётся только из защищённого `NAVIGATOR_ADMIN_TELEGRAM_ID`.

После проверки выпуска записывается `PUBLICATION_VERIFIED`, после подтверждения карточек — `TELEGRAM_DELIVERED`, после подтверждения меню — `TELEGRAM_MENU_DELIVERED`.

Каждое из двух сообщений отправляется одной попыткой. Тайм-аут может означать, что Telegram принял сообщение, поэтому слепого автоматического повтора нет. Если карточки подтверждены, а меню — нет, Summary содержит `TELEGRAM_MENU_UNCONFIRMED`: открыть `/start`. Новый явный запуск может создать повторное сообщение.

Если ссылка не пришла, проверить Summary нужного запуска Actions. Публикация и доставка имеют отдельные результаты; ссылку также можно скопировать на табло. Периодическое обновление без `notice_event` не отправляет сообщений.

## Ссылки и доступ

Формат: `?v=<run>.<attempt>#card=p04&round=17`. `cardId` постоянный, круг закреплён; данные по ссылке могут обновляться вместе с табло. Кнопки просмотра, скачивания PNG и копирования на сайте сохраняются.

Карточки доступны публично. Персональная ссылка выбирает карточку и не закрывает данные паролем. ID таблиц из `buildin-sync.json` видны в исходниках; без API-токена они не дают права читать или менять Buildin.

Настройки секретов и расписания — в `BUILDIN-SYNC.md`. Для работы цепочки достаточно Telegram, Beget, Buildin и GitHub.
